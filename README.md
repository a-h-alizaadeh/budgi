# Wallet (کیف پول شخصی)

اپ اندروید مدیریت مالی شخصی (راست‌به‌چپ) — Kotlin + Jetpack Compose + Room.

امکانات: چندارزی با نرخ دستی، تاریخ شمسی، دسته‌بندی درختی، قالب‌ها، یادداشت‌های کارتی (چک‌لیست/رنگ/پین)، گارانتی‌ها، کارت‌های وفاداری، مکان‌ها، رمز و اثر انگشت، خروجی PDF/XLSX/CSV و ورود CSV، هزینه‌های مورد انتظار با شمارش معکوس، پس‌انداز، قالب‌بندی یادداشت (فونت/بولد/ایتالیک/زیرخط/اندازه/تراز/رنگ).

فونت‌ها: وزیرمتن، شبنم و گندم (مجوز SIL OFL / آزاد) داخل `res/font` قرار دارند.

## ساخت APK
1. همه‌ی فایل‌ها (به‌همراه پوشه‌ی مخفی `.github` و فایل `app/debug.keystore`) را در ریپازیتوری گیت‌هاب آپلود کنید (شاخه‌ی `main`).
2. تب **Actions** ← **Build Android APK** خودکار اجرا می‌شود (یا Run workflow).
3. از انتهای صفحه‌ی اجرا، **wallet-debug-apk** را از Artifacts دانلود و نصب کنید.

## نکات مهم
- شناسه‌ی برنامه `com.personal.wallet` و نام آن «Wallet» است (همان برنامه‌ی قبلی).
- `app/debug.keystore` کلید امضای ثابت است؛ با آن، نسخه‌های بعدی روی نسخه‌ی قبلی نصب می‌شوند و داده‌ها پاک نمی‌شود.
  این کلید آزمایشی است. اگر ریپازیتوری public است و برنامه را جدی می‌خواهید، کلید اختصاصی بسازید.
- **نصب اول:** اگر نسخه‌ی قدیمی با کلید امضای دیگری ساخته شده باشد، اندروید اجازه‌ی نصب روی آن را نمی‌دهد (خطای «App not installed»)؛ مجبور می‌شوید قدیمی را حذف کنید و داده‌های آن از بین می‌رود. پیش از حذف، اطلاعات مهم را یادداشت کنید.
- قبل از هر به‌روزرسانی، از منوی کشویی ← خروجی‌ها فایل بگیرید.
